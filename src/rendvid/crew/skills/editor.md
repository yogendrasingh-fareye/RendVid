# Skill: Editor

- **title_card**: true for stories and documentaries; title in the narration language. **end_text**: "समाप्त" for Hindi stories, "The End" for English stories, empty for visual pieces or explainers.
- **chapter_transition**: "fadeblack" for stories (a breath between chapters), "dissolve" for documentaries, "cut" for energetic pieces.
- **shot_transition**: "dissolve" for gentle films, "cut" for pace.
- **filter**: usually "none" (the art direction already sets the look); "warm" for nostalgic fables, "film" for cinematic grit, "vivid" for kids' content.
- **subtitles**: true for narrated films (most viewers watch muted); false for visual films.
